Privacy Policy

Last updated: November 12, 2026

Upload Phim ("the app") is a desktop tool that runs on the user's own computer and uploads videos to YouTube channels the user owns or manages. This policy explains what data the app accesses and how it is handled.

Data the app accesses

  • Google account email address, to show which account is connected.
  • YouTube channel ID and title, to show which channel videos are uploaded to.
  • OAuth access and refresh tokens, to upload videos, set thumbnails, add videos to playlists and check processing status on the user's behalf.
  • Video files and metadata chosen by the user, such as titles, descriptions, tags and schedules.

How the data is used

The data is used only to perform the uploads and scheduling the user asks for. The app does not use the data for advertising, profiling, analytics or any other purpose.

Storage and sharing

  • All data, including tokens, is stored only on the user's own computer in local files with restricted permissions.
  • The app has no server. No data is sent to the developer or to any third party. Data is sent only to Google and YouTube APIs to perform the requested actions.
  • The app does not sell, rent or share user data.

YouTube API Services

The app uses YouTube API Services. Use of the app is subject to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

You can revoke the app's access at any time at Google Account permissions. Removing an account inside the app deletes its stored tokens from your computer. Deleting the app's data folder deletes all locally stored data.

Contact

Questions about this policy can be submitted via GitHub Issues.
